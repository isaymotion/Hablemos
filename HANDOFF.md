## 5. Pitfalls learned
- Pass 6: `.eyebrow` text is uppercased by CSS, so Playwright `inner_text` returns capitals ("YOUR LEVEL"); compare lowercased. The dictionary parser dedupes on spanish+english only, so a word with two senses must have two different English glosses or the second is silently dropped. When two agents write dictionary files in parallel, give each a disjoint category list and dedupe filler words afterwards (done for dict-more).
- Pass 5: a `"..."` quote inside a double-quoted JS string in `psych-cases.js` broke the whole data load (data_check and every view); when patching data files by script, check `node -e` loads the file afterwards. Smoke's `[data-ask]` buttons re-render after each click, so click them by `data-ask` value (re-queried each time), not from a stale `.all()` list.
- Discharge `diagnosis` and `medications` picks have no AUD/OUD, naltrexone or buprenorphine entries; cases use "Other comorbid: ___" and generic picks and put the drug in `doc`. If she wants them as picks, append to `picks` (strings, append-only) and update the five cases' `need`.
- `mse-practice.js` compares admission vs discharge by case id, so an admission case must have a discharge case with the same id (data_check enforces it).
- Files to re-attach: none. Everything the next chat needs is in the two repos (Hablemos main + dev-tools, Usap Tayo for reference). Scratch extracts of Usap Tayo's English lines are regenerated with the vm snippet in step 1 of the recipe.
