# Hablemos pass 11 (0.10.0 psychiatry expansion): shared drafting brief

Hablemos is a Spanish/English web app for English-speaking clinicians (residents and nurses) interviewing Spanish-speaking psychiatry patients in the US. It shares its JavaScript engine with sister apps, so **data shapes and field names are fixed**. You write ONE OR TWO NEW data files in `/home/claude/hablemos/js/data/` (named in your task). **Create new files only. Do not edit any existing file, do not touch `index.html`, `sw.js`, git, or other agents' files.** Other agents are writing sibling files at the same time.

## Hard rules
- Plain JavaScript, no build step. Each new file APPENDS to its global (`window.X = (window.X || []).concat([...])`, or `.push`, or the merge shown in your task). Start the file with a header comment that says what it holds and **"STATUS: DRAFT FOR REVIEW by a native Spanish-speaking clinician"**.
- Field names `tl` / `f` / `c` stay (engine). `tl` = the Spanish text. `f` = usted form (default with adults). `c` = hand-written tú form (not a mechanical swap: natural everyday wording). `en` = natural US clinical English. `n` = optional English note for the clinician (technique, gender, regional variant, safety). For a child or teenager both forms use tú. For Don / Doña + first name, usted in both.
- Spanish: US / Mexican baseline, natural spoken register. Correct accents, ¿…? and ¡…!. Gender-mark adjectives for the speaker; where the clinician's line depends on the patient's gender, write the masculine and say so in `n` ("decaído / decaída"). Regional words may appear in patient speech (nervios, ataque de nervios, susto, coraje, malilla, la cruda, cristal, mota, las azules, curandero, botánica, "un trabajo", la migra) with a gloss in the English or the note.
- **US context.** Emergency number 911. Crisis line **988** (Suicide and Crisis Lifeline; "oprima el 2" for Spanish). The hospital is unnamed ("the hospital", "la unidad", "la clínica"). Inpatient psychiatry unit = "la unidad"; nurses' station = "la estación de enfermería"; call button = "el botón de llamada" (regional: "el timbre"). As-needed medicine = "una medicina para cuando la necesite". Mention a qualified interpreter where consent, teaching or risk is involved (Title VI). Ward rules differ: notes say "check your unit's policy" rather than inventing rules.
- **No staff-to-staff Spanish.** In a US hospital the nurse reports to the doctor in English. Where the reference has a nurse phoning the doctor (SBAR), write instead what the nurse says in Spanish **to the patient or family** at that moment ("Voy a llamar al doctor para que venga a verlo."), and put the SBAR reminder in English in `n`.
- **Forbidden anywhere** (grep before finishing): `po`, `kayo`, `opo`, `ninyo`, `Tagalog`, `Filipino`, `Mariveles`, `NCMH`, `1553`, `barangay`, `shabu`, `peso`, `MMH-`, and anything Japanese (kana, kanji, `さん`, `119`, Kimura and other Japanese names or places). The reference files come from the Japanese sister app: **copy structure, teaching points and English clinical content; rewrite names, places, culture and every language note for Spanish speakers in the US.** Never translate a Japanese-language note; write the note a Spanish learner needs, or drop it.
- Fictional patients only: first names (or Don / Doña + name), age, occupation. No surnames, record numbers, real staff names, dates of birth. The clinician is "doctor / doctora" or "enfermero / enfermera" with a blank `___` for the name.
- Clinical content: DSM-5-TR, standard US practice. Medicine examples with generic names and realistic adult doses only in case charts and `doc`, as teaching examples. In nurse scripts: no medicine names, no doses. **No method detail** for suicide or self-harm, no amounts for overdose or misuse, no product brand names. Do not reproduce copyrighted instruments (no MMSE, MoCA, C-SSRS, Y-BOCS, PCL-5 item wording); paraphrase and name the instrument only as something to administer separately.
- No stigmatizing terms as correct answers (loco, drogadicto, viciosa); they may appear as a score-0 choice whose feedback explains why, or in a family member's mouth.
- English writing style (feedback, notes, `why`, `doc`): plain, active, short sentences, no em-dash asides, no semicolon chains. Feedback teaches the interviewing skill.
- JS string safety: use backticks or single quotes consistently; a `"` inside a double-quoted string breaks the whole app. After writing, run `node --check <your file>`.
- Copy each finished file into place as soon as it is done (do not hold everything to the end).
- Validation when done: `cd /home/claude/hablemos && node /home/claude/hablemos-dev/tests/data_check.js .` must show **no ERROR line that names your file or your ids** (errors about other agents' unfinished files are not yours; WARN lines are fine). Fix every ERROR of yours.
- Report back (short): counts per file, the 8 to 12 Spanish lines you are least sure of (for the native-speaker reviewer), and anything you had to interpret.

## Shape reminders
- Case simulation: `{ id, title, level, role?: 'nurse', setting, steps: [{ who, line: [es, en], choices: [{ tl, en, score: 0|1|2, fb }] }], summary: { findings: [..], mse: '..' } }`; every step has **exactly one** score-2 choice and 3 choices; vary the position of the best choice.
- Interp item: `[es, en (with a literal gloss in parentheses where it helps), significance]`.
- Discharge / end-of-treatment case field: `{ obs?, ans: { qIdx: [es, en, speaker?] }, key?: [qIdx], need: [pick or [any-of picks]], ok?: [picks], wrong?: { pick: why }, doc, why, quote? }`; the model answer (`need`) must grade as a full match; `decision: { discharge: bool, why }` (discharge) or `{ end: bool, why }` (end-of-treatment).
- Admission MSE case: `{ id, title, level, dx, form: '', setting, chart, cc: { ask: 'collateral:1' or another phrase ref, ans: [es, en, who], opts: [[text, correct, why]] (one correct) }, domains: { <13 ids>: { obs?, ans: { qIdx: [es, en] }, key?, need, ok?, wrong?, doc, why, quote?, ev?: { find, opts: [[text, correct]], why } } } }`; 4 `ev` evidence questions per case.
